## 2024-03-18 - Semantic HTML main tag for Landing Page
**Learning:** Using a `<main>` tag instead of a `<div class="wrap">` creates a landmark that screen readers can easily navigate to, improving accessibility for the static landing page.
**Action:** Always look for opportunities to replace generic `<div>` wrappers with semantic HTML5 tags like `<main>`, `<nav>`, `<article>`, or `<aside>` where appropriate.
